# 星芽少儿编程 · 课程介绍（合成示例文档）

## 课程体系

星芽少儿编程面向 6-14 岁孩子，设三阶课程：

| 阶段 | 课程 | 内容 | 适合年龄 |
|------|------|------|----------|
| 启蒙 | Scratch 趣味编程 | 图形化拖拽，做小游戏和动画 | 6-8 岁 |
| 进阶 | Python 少儿编程 | 真实代码，算法思维入门 | 9-11 岁 |
| 高阶 | C++ 信竞班 | 信息学竞赛备考 | 12-14 岁 |

## 常见问题

### 需要自带电脑吗

不需要，校区有机房设备，课后可在家用任意电脑练习。

### 请假怎么补课

提前在班主任处预约，即可安排其他班次补课，不额外收费。

### 退费政策

提交退费申请后 7 个工作日内审核，原路退回剩余课时费用。
